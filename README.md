# Student Management System
### Built with ASP.NET Core MVC

## About
A web-based Student Management System built using ASP.NET Core MVC 
with Identity Authentication and Role-Based Authorization.

## Features
- User Registration and Login
- Role-Based Access Control (Admin and User roles)
- Admin can view all students, view detail and delete students
- User can enroll as a student, view and edit their own detail
- Photo upload for student profiles
- Student search and pagination
- SQLite database

## Technologies Used
- ASP.NET Core MVC
- Entity Framework Core
- SQLite
- ASP.NET Core Identity
- Bootstrap
- C#

## How to Run
1. Clone the repository
2. Open in Visual Studio 2022
3. Run the project
4. Default admin account:
   - Email: admin@school.com
   - Password: Admin@1234
5. Register a new account to access User features
